# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/AzureAD/ms-eeid-agent-toolkit/issues)
to track bugs and feature requests. Search the existing issues before filing a
new one to avoid duplicates. Use the issue templates, and include the skill
name, its skill version (`metadata.version` in its `SKILL.md`), and the
assistant you used.

For questions about using these skills, open an issue as well. For questions
about Microsoft Entra External ID itself, see the
[Microsoft Entra External ID documentation](https://learn.microsoft.com/entra/external-id/customers/)
and [Microsoft Q&A](https://learn.microsoft.com/answers/tags/455/entra-id).

Report security issues as described in [SECURITY.md](SECURITY.md), not in an
issue.

## Microsoft Support Policy

Support for this project is limited to the resources listed above. Issues are
handled on a best-effort basis.
